# 휴먼 라이크 자동 타이핑기 (Auto-Typer) 설계 문서

## 1. 프로젝트 개요
본 프로젝트는 **Windows 11** 환경을 최우선 타겟으로 하며(추후 macOS 확장 가능 구조), 사용자가 텍스트를 붙여넣으면 **실제 사람이 키보드의 자소(한글 2벌식 자음/모음)와 영문 키를 하나씩 직접 누르는 것처럼** 하드웨어 스캔코드(`SendInput`) 이벤트를 발생시키는 GUI 프로그램입니다.
- 현재 열려 있는 창 목록(메모장 등)을 드롭다운에서 선택해 자동으로 포커스를 맞추거나 카운트다운 후 타이핑을 시작합니다.
- Windows `imm32.dll` API를 통해 대상 창의 실시간 한/영(IME) 상태를 감지하여 한/영이 꼬이지 않도록 자동 전환합니다.
- 지정된 타수(예: 200~300타/분) 범위 내 랜덤 속도와 정확도(0~100%) 기반의 인간형 오타 발생 및 `Backspace` 교정(최종 결과물 100% 일치)을 수행합니다.

---

## 2. 확정된 핵심 요구사항
1. **개발 환경 및 GUI**:
   - Python 3.11 (`.venv` 가상환경) + `CustomTkinter` (모던 다크/라이트 UI).
2. **대상 창(메모장 등) 지정 방식 (두 가지 모두 지원)**:
   - **방식 A (창 선택 모드)**: 현재 열려 있는 윈도우 목록(예: `제목 없음 - Windows 메모장`)을 드롭다운에서 선택하고 시작하면 프로그램이 해당 창을 자동으로 최상단 활성화(`SetForegroundWindow`)한 뒤 타이핑 시작.
   - **방식 B (수동 포커스 카운트다운 모드)**: 시작 버튼 클릭 후 카운트다운(예: 3초) 동안 사용자가 원하는 창을 직접 클릭하여 포커스.
3. **자소 단위 실제 키 입력 (Hardware ScanCode `SendInput`)**:
   - 한글 완성형 글자(`가`~`힣`)를 2벌식 자소(`ㄱ`, `ㅏ` 등)로 분해하여 개별 키 스캔코드로 입력.
   - 쌍자음(`ㄲ`, `ㄸ`, `ㅃ`, `ㅆ`, `ㅉ`) 및 복합모음(`ㅒ`, `ㅖ`)은 `Shift + 기본키` 조합 입력.
   - 복합모음(`ㅘ`, `ㅝ`, `ㅢ` 등) 및 겹받침(`ㄳ`, `ㄺ`, `ㅄ` 등)은 2타로 나누어 순차 입력.
4. **Windows 네이티브 한/영(IME) 자동 감지 및 전환**:
   - `imm32.dll` (`ImmGetDefaultIMEWnd`, `WM_IME_CONTROL`)을 사용하여 현재 활성화된 대상 창의 IME가 한글 모드인지 영문 모드인지 실시간 조회하거나 내부 상태를 동기화하고, 필요 시 `VK_HANGUL`(`0x15`) 키를 눌러 정확히 전환.
5. **타수(CPM) 기반 랜덤 타이핑 속도**:
   - 최소 타수(예: 200타) ~ 최대 타수(예: 300타) 설정 시 매 타건마다 해당 범위 내에서 딜레이($\Delta t = \frac{60}{\text{CPM}}$)를 랜덤 계산.
6. **정확도(0% ~ 100%) 및 오타 후 100% 수정 시뮬레이션**:
   - `(100 - 정확도)%` 확률로 실제 키보드에서 인접한 자소 키를 잘못 입력.
   - 사람처럼 오타 인지 딜레이(`150ms ~ 350ms`) 후 `Backspace`를 눌러 오타 자소를 지우고 원래의 정상 자소를 입력하여 **최종 완성된 텍스트는 원본과 100% 일치**하도록 보장.
7. **비상 정지 단축키(Global Hotkey)**:
   - 타이핑 도중 언제든 `ESC` (또는 `F12`) 키를 누르면 즉시 타이핑 중단.

## 3. 시스템 아키텍처 및 디렉토리 구조

```text
d:\rpa\auto_type\
├── .venv/                      # Python 가상환경
├── docs/
│   ├── design.md               # 시스템 설계 문서
│   └── implementation_plan.md  # 단계별 구현 계획
├── src/
│   ├── __init__.py
│   ├── main.py                 # 애플리케이션 엔트리 포인트
│   ├── gui/
│   │   ├── __init__.py
│   │   └── app_window.py       # CustomTkinter 메인 GUI (창 선택, 속도/정확도 설정, 상태 표시)
│   ├── core/
│   │   ├── __init__.py
│   │   ├── models.py           # KeyStroke, TypingAction 등 데이터 모델
│   │   ├── decomposer.py       # 한글 2벌식 자소 분해 및 키 시퀀스 변환기
│   │   ├── typo_generator.py   # QWERTY/2벌식 인접 키 맵 및 오타/Backspace 복구 시퀀스 생성기
│   │   ├── timing_engine.py    # 타수(CPM) 범위 기반 랜덤 딜레이 계산기
│   │   └── typer_worker.py     # 백그라운드 타이핑 스레드 및 일시정지/중단 제어
│   └── os_driver/
│       ├── __init__.py
│       ├── win32_window.py     # 열려 있는 창 목록 조회, 창 활성화(Focus), IME 한/영 상태 조회
│       └── keyboard_driver.py  # Win32 SendInput 하드웨어 키 입력 및 한/영 전환 드라이버
├── tests/
│   └── test_core.py            # 자소 분해 및 오타 복구 시뮬레이션 단위 테스트
└── requirements.txt            # 의존성 패키지 목록
```
