# 구현 계획서 (Implementation Plan)

본 문서는 [설계 문서](design.md)를 바탕으로 크로스 플랫폼 휴먼 라이크 자동 타이핑 프로그램을 구현하기 위한 단계별 계획입니다.

---

## Phase 1: 프로젝트 환경 구성 (`.venv` 및 의존성 설치)
1. 프로젝트 루트(`d:\rpa\auto_type`)에 `.venv` 파이썬 가상환경 생성.
   - `python -m venv .venv`
2. 필수 패키지 정의 (`requirements.txt`) 및 설치:
   - `customtkinter`: 모던 크로스 플랫폼 GUI 프레임워크
   - `pynput`: Windows / macOS 키보드 제어 및 글로벌 단축키 리스너
   - `pytest`: 핵심 알고리즘(한글 분해, 오타 시퀀스 생성) 단위 테스트용

---

## Phase 2: 한글/영문 자소 분해 및 액션 스트림 엔진 (`src/core/`)
1. **한글 2벌식 분해기 (`src/core/decomposer.py`)**:
   - 입력된 전체 문자열을 순회하며 각 글자를 분석.
   - 완성형 한글(`가`~`힣`) 및 호환용 한글 자모(`ㄱ`~`ㅣ`)를 2벌식 키보드 타건 단위(`KeyStroke` 객체: 물리 키, `shift` 여부, 언어 모드 `KO`/`EN`/`NEUTRAL`)로 분해.
   - 복합 모음(`ㅘ`, `ㅙ`, `ㅚ`, `ㅝ`, `ㅞ`, `ㅟ`, `ㅢ`)과 겹받침(`ㄳ`, `ㄵ`, `ㄶ`, `ㄺ` 등)의 2타 분리 매핑 테이블 구축.
   - 영문 대소문자, 숫자, 특수문자(`!@#$%^&*()` 등 Shift 조합 포함), 줄바꿈(`\n`), 탭(`\t`) 처리.
2. **오타 및 교정 생성기 (`src/core/typo_generator.py`)**:
   - QWERTY 키보드 기준 물리적 인접 키(상하좌우 대각선) 사전 정의.
   - 설정된 정확도(`0% ~ 100%`)에 따라 각 타건마다 오타 발생 여부 결정.
   - 오타 발생 시:
     1) 인접한 잘못된 키 입력 액션 생성
     2) 인지 대기 딜레이(`Reaction Delay`, 약 150~350ms) 삽입
     3) `Backspace` 키 액션 삽입
     4) 재입력 대기 딜레이 후 원래의 정상 키 액션 삽입
   - 연속 무한 오타 방지를 위해 교정 직후 타건은 정상 입력 보장(또는 최대 재시도 횟수 제한).
3. **타수(CPM) 기반 타이밍 엔진 (`src/core/timing_engine.py`)**:
   - 최소 타수(예: 200) ~ 최대 타수(예: 300) 범위 내에서 매 타건의 딜레이($\frac{60}{\text{CPM}}$)를 랜덤 추출.
   - 키 누름 유지 시간(Key Press Duration: `25ms ~ 60ms`) 랜덤 생성.
   - 공백, 마침표, 엔터키 입력 후 자연스러운 문장 호흡 딜레이 옵션 반영.

## Phase 3: OS별 키보드 드라이버 및 한/영 제어 (`src/platform/`)
1. **키보드 입력 드라이버 (`src/platform/keyboard_driver.py`)**:
   - `pynput.keyboard.Controller`를 래핑하여 물리 키 누름(`press`) 및 뗌(`release`) 수행.
   - **Windows 11 한/영 제어**:
     - `VK_HANGUL` (`0x15`) 키 이벤트 송출.
     - (선택/자동 감지) Windows `imm32.dll` API를 통해 대상 창의 현재 IME가 한글인지 영문인지 직접 확인하거나 내부 상태 추적을 통해 한/영 전환 수행.
   - **macOS 한/영 제어**:
     - macOS 사용자 환경에 맞춰 한/영 전환 키를 선택할 수 있도록 지원 (`Caps Lock`, `Ctrl + Space`, `Command + Space`, `Right Option` 등).
2. **글로벌 비상 정지 핫키 리스너**:
   - 타이핑 도중 마우스/키보드 제어권을 즉시 되찾을 수 있도록 `ESC` 또는 `F12` 키 입력 시 즉시 작업을 중단(Stop)하거나 일시정지(Pause)하는 글로벌 리스너 구현.

---

## Phase 4: GUI 애플리케이션 구현 (`src/gui/`)
1. **메인 윈도우 (`src/gui/app_window.py`)**:
   - **텍스트 입력 영역**: 타이핑할 원고 텍스트를 붙여넣을 수 있는 멀티라인 텍스트 박스 (글자 수 및 예상 타건 수 실시간 표시).
   - **속도 설정 영역**: 최소 타수 ~ 최대 타수 입력 필드 또는 슬라이더 (기본값: `200` ~ `300` 타/분).
   - **정확도 설정 영역**: `0% ~ 100%` 슬라이더 및 수치 입력 (기본값: `95%`).
   - **한/영 및 시작 옵션 영역**:
     - 시작 전 대기 시간(카운트다운: 3초 / 5초 / 10초) 설정 (메모장 창을 클릭할 시간 확보).
     - 초기 IME 상태 또는 OS별 한/영 전환 키 설정.
   - **진행 상태 표시줄 (Progress Bar & Status)**:
     - 카운트다운 표시 (`3초 후 타이핑을 시작합니다... 메모장을 클릭하세요!`).
     - 현재 진행률(%) 및 실시간 타수, 오타 발생/수정 횟수 로그 표시.
   - **제어 버튼**: `시작(Start)`, `일시정지/재개(Pause/Resume)`, `정지(Stop, ESC)`.

---

## Phase 5: 테스트 및 검증
1. **단위 테스트 (`tests/`)**:
   - 한글 자소 분해 테스트 (예: `"안녕하세요 Hello 123!"` -> 정확한 키 시퀀스 및 한/영 전환 토큰 생성 검증).
   - 정확도 0%, 50%, 100% 설정 시 오타 및 `Backspace` 시퀀스 정합성 검증.
2. **통합 테스트**:
   - Windows 11 메모장(Notepad)을 띄워두고 한글/영문 혼용 문장, 줄바꿈, 특수문자, 오타 발생 후 백스페이스 수정이 사람처럼 자연스럽게 동작하는지 검증.
