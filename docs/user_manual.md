# Auto-Typer (휴먼 라이크 자동 타이핑기) 사용자 설명서

본 문서는 **Auto-Typer** 프로그램의 설치, 실행 방법 및 주요 기능 사용법을 안내합니다.

---

## 1. 프로그램 소개

**Auto-Typer**는 화면에 입력(또는 붙여넣기)한 텍스트를 메모장, 워드프로세서, 웹 브라우저 등 원하는 창에 **실제 사람이 키보드를 한 타씩 직접 치는 것과 동일하게** 타이핑해 주는 프로그램입니다.

### ✨ 주요 특징
- **자소 단위 리얼 타이핑**: 완성된 글자를 붙여넣는 방식이 아니라, 한글 2벌식 자음/모음(`ㅎ` → `하` → `한`), 쌍자음(`Shift` + 단자음), 복합모음(`ㅘ` → `ㅗ`+`ㅏ`), 겹받침(`ㄺ` → `ㄹ`+`ㄱ`)을 실제 키보드 스캔코드로 하나씩 입력합니다.
- **한/영 자동 감지 및 전환**: 한글과 영문이 섞여 있어도 대상 창의 현재 한/영(IME) 상태를 자동으로 감지하여 알아서 `한/영` 키를 눌러 전환합니다.
- **랜덤 타수(CPM) 속도 제어**: 예를 들어 `200 ~ 300타`로 설정하면 매 타건마다 해당 범위 안에서 속도가 자연스럽게 변하며, 마침표나 줄바꿈 뒤에는 사람처럼 짧은 호흡(멈칫함)을 둡니다.
- **오타 발생 및 자동 수정 (`Backspace`)**: 설정한 정확도(`0% ~ 100%`)에 따라 실제 키보드에서 인접한 키를 잘못 누른 뒤, 잠시 멈칫하고 `Backspace`를 눌러 지운 후 원래 글자를 다시 입력하여 **최종 결과물은 원본과 100% 일치**하게 만듭니다.

## 2. 실행 방법

### 방법 1: 배치 파일로 간편 실행 (권장)
1. 프로젝트 폴더(`d:\rpa\auto_type`) 안에 있는 **`run.bat`** 파일을 더블 클릭합니다.
2. 잠시 후 **Auto-Typer** GUI 창이 나타납니다.

### 방법 2: 터미널(PowerShell / 명령 프롬프트)에서 실행
프로젝트 폴더에서 아래 명령어를 입력합니다.
```powershell
.\.venv\Scripts\python.exe src\main.py
```

## 3. 화면 구성 및 단계별 사용법

```text
+-----------------------------------------------------------------------+
| 🎯 타이핑 대상 창: [ 🪟 제목 없음 - Windows 메모장 ▼ ] [🔄 창 목록 새로고침] |
+-----------------------------------------------------------------------+
| 📝 타이핑할 텍스트 입력                  글자 수: 95자 | 예상 타건: 240타 [지우기] |
| +-------------------------------------------------------------------+ |
| | 안녕하세요! 여기에 타이핑할 내용을 붙여넣으세요.                       | |
| | Hello World! 한글과 영문을 알아서 전환하며 입력합니다.                 | |
| +-------------------------------------------------------------------+ |
+-----------------------------------------------------------------------+
| ⚡ 타이핑 속도 범위 (분당 타수):  [ 200 ] 타 ~ [ 300 ] 타/분              |
| 🎯 타이핑 정확도 (오타 & 수정):  [=======O---] [ 94 ] %                  |
| ⏱️ 시작 전 준비 시간:           [ 1초 | 3초 | 5초 | 10초 ]               |
+-----------------------------------------------------------------------+
| 대기 중 — 대상 창을 선택하고 [타이핑 시작]을 눌러주세요.                    |
| [===================================================================] |
| [ ▶ 타이핑 시작 (Start) ]  [ ⏸ 일시정지 (Pause) ]  [ ⏹ 정지 (Stop / ESC) ] |
+-----------------------------------------------------------------------+
```

### Step 1. 타이핑할 대상 창(메모장 등) 준비 및 선택
타이핑을 받을 창을 지정하는 방법은 **2가지**가 있습니다.

1. **창 목록에서 자동 선택 (권장)**
   - 먼저 Windows **메모장(Notepad)** 등 타이핑을 입력받을 프로그램을 실행해 둡니다.
   - Auto-Typer 우측 상단의 **`🔄 창 목록 새로고침`** 버튼을 클릭합니다.
   - 드롭다운 메뉴에서 `🪟 제목 없음 - Windows 메모장` (또는 원하는 창)을 선택합니다. (메모장이 열려 있으면 새로고침 시 자동으로 선택됩니다.)
   - 이후 시작 버튼을 누르면 카운트다운이 끝난 뒤 **프로그램이 알아서 해당 메모장 창을 맨 앞으로 활성화**하고 타이핑을 시작합니다.
2. **수동 포커스 모드**
   - 드롭다운 메뉴 맨 위의 **`⚡ [수동 포커스] 카운트다운 동안 직접 마우스로 창 클릭하기`**를 선택합니다.
   - **`▶ 타이핑 시작`** 버튼을 누른 뒤 카운트다운(예: 3초)이 진행되는 동안, 마우스로 메모장 등 원하는 입력 칸을 직접 클릭해 커서를 깜빡이게 두면 그곳에 타이핑됩니다.

### Step 2. 텍스트 입력
- 중앙의 텍스트 상자에 타이핑할 원고를 입력하거나 붙여넣기(`Ctrl + V`) 합니다.
- 우측 상단에 실시간으로 **글자 수**와 **예상 타건(자소) 수**가 계산되어 표시됩니다.
- 내용을 모두 지우려면 **`지우기`** 버튼을 누릅니다.

### Step 3. 세부 옵션 설정
1. **⚡ 타이핑 속도 범위 (분당 타수)**
   - 최소 타수와 최대 타수를 입력합니다 (기본값: `200` ~ `300` 타/분).
   - 일반적인 사람의 자연스러운 타이핑 속도는 `200 ~ 350` 타/분, 빠른 속도는 `400 ~ 600` 타/분입니다.
2. **🎯 타이핑 정확도 (오타 & 수정)**
   - 슬라이더를 움직이거나 숫자를 직접 입력하여 `0% ~ 100%` 사이로 설정합니다.
   - **`100%`**: 오타 없이 한 번에 정확히 입력합니다.
   - **`90% ~ 97%` (추천)**: 실제 사람이 타이핑하다가 가끔 인접한 키 오타를 내고 `Backspace`로 지운 뒤 다시 고쳐 쓰는 가장 자연스러운 설정입니다.
   - **`0% ~ 50%`**: 오타와 백스페이스 수정을 매우 빈번하게 발생시킵니다. (단, 어떤 정확도를 설정하더라도 모든 오타는 스스로 수정하므로 **최종 완성된 문장은 원본과 100% 일치**합니다.)
3. **⏱️ 시작 전 준비 시간**
   - `1초`, `3초`, `5초`, `10초` 중 시작 버튼을 누른 뒤 실제 타이핑이 시작되기까지의 카운트다운 시간을 선택합니다.

### Step 4. 타이핑 시작 / 일시정지 / 비상 정지
- **`▶ 타이핑 시작 (Start)`**: 카운트다운 후 타이핑을 시작합니다. 하단 상태 표시줄과 진행률 바에서 현재 입력 중인 자소, 실시간 타수, 오타 수정 횟수를 확인할 수 있습니다.
- **`⏸ 일시정지 (Pause)` / `▶ 재개 (Resume)`**: 타이핑 도중 잠시 멈추거나 멈춘 지점부터 이어서 타이핑할 수 있습니다.
- **`⏹ 정지 (Stop / ESC)`**: 타이핑을 완전히 중단합니다.

> [!IMPORTANT]
> **🚨 비상 정지 단축키 (`ESC` 또는 `F12`)**
> 타이핑이 진행되는 도중에는 키보드 입력이 계속 발생하므로 마우스로 정지 버튼을 누르기 불편할 수 있습니다. 이때 키보드의 **`ESC`** 키 또는 **`F12`** 키를 누르면 어떤 창이 활성화되어 있든 **즉시 타이핑이 중단**됩니다.

## 4. 자주 묻는 질문 (FAQ) 및 주의사항

### Q1. 타이핑 도중에 다른 창을 클릭하면 어떻게 되나요?
- 본 프로그램은 실제 키보드 하드웨어 신호를 발생시키므로, 타이핑 도중 마우스로 다른 창을 클릭하면 클릭한 창에 글자가 입력됩니다.
- 다른 작업을 해야 할 때는 먼저 **`ESC`** 키를 눌러 정지하거나 **`⏸ 일시정지`** 버튼을 눌러주세요.

### Q2. 메모장의 현재 한/영 상태가 한글이든 영문이든 상관없나요?
- 네, 상관없습니다. Windows의 IME 상태 감지 기능(`imm32.dll`)을 통해 현재 메모장이 한글 상태인지 영문 상태인지 자동으로 확인한 뒤, 입력할 글자에 맞춰 알아서 `한/영` 전환 키를 누릅니다.

### Q3. 일부 관리자 권한 프로그램에서 타이핑이 안 될 때는 어떻게 하나요?
- 만약 타이핑 대상 프로그램이 **관리자 권한**으로 실행된 프로그램이라면, Windows 보안 정책(UIPI)상 Auto-Typer도 관리자 권한으로 실행해야 키 입력이 전달됩니다. 일반 메모장이나 브라우저 등에서는 일반 권한으로 바로 동작합니다.
