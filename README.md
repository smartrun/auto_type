# Auto-Typer ⌨️

> **크로스 플랫폼 휴먼 라이크 자동 타이핑 프로그램**  
> 화면에 텍스트를 붙여넣으면 실제 사람이 키보드의 자소(한글 2벌식 자음/모음)와 영문 키를 하나씩 직접 치는 것처럼 자연스럽게 타이핑합니다.

---

## 🌟 주요 기능

1. **자소 단위 실제 하드웨어 입력 (Human-like Keystroke)**
   - 완성형 텍스트를 단순히 붙여넣는 방식이 아닙니다.
   - 한글 2벌식 초성·중성·종성, 쌍자음(`Shift` 조합), 복합모음(`ㅘ` $\rightarrow$ `ㅗ`+`ㅏ`), 겹받침(`ㄺ` $\rightarrow$ `ㄹ`+`ㄱ`)을 하드웨어 스캔코드 수준으로 직접 입력하여 메모장에서 글자가 조합되는 과정(`ㅎ` $\rightarrow$ `하` $\rightarrow$ `한`)이 실제 사람이 치는 것처럼 나타납니다.
2. **지능형 한/영 자동 감지 및 전환**
   - Windows의 IME 상태(`imm32.dll`)를 실시간으로 확인하여 한글/영문 입력 시 필요한 경우에만 자동으로 `한/영` 키를 전환합니다.
   - 공백, 숫자, 일반 기호는 현재 상태를 유지하여 불필요한 전환을 방지합니다.
3. **타수(CPM) 범위 기반 랜덤 속도 제어**
   - 사용자가 최소 타수 ~ 최대 타수(예: `200 ~ 300타/분`)를 지정하면, 매 타건마다 해당 범위 내에서 가우시안 랜덤 딜레이를 계산하여 사람 특유의 리듬감을 연출합니다.
   - 마침표(`.`), 쉼표(`,`), 줄바꿈(`\n`) 뒤에는 짧은 호흡(멈칫함)을 모사합니다.
4. **정확도(0% ~ 100%) 기반 오타 발생 및 백스페이스 교정**
   - 설정한 정확도에 따라 QWERTY/2벌식 인접 키를 잘못 누르는 인간형 오타를 냅니다.
   - 한글 음절 조합이 깨지지 않도록 자음 위치에는 자음 오타, 모음 위치에는 모음 오타를 발생시키며, 사람처럼 인지 딜레이 후 `Backspace`로 지우고 원래 글자를 다시 입력합니다.
   - **어떤 정확도로 설정하더라도 최종 결과물은 원본 텍스트와 100% 일치합니다.**
5. **대상 창(메모장 등) 자동 포커스 및 수동 카운트다운 지원**
   - 현재 열려 있는 윈도우 목록을 자동으로 감지하여 메모장 창을 최상단으로 활성화한 후 타이핑합니다. (수동 클릭 모드도 지원)
6. **비상 정지 단축키 (Global Hotkey)**
   - 타이핑 도중 언제든 키보드의 **`ESC`** 또는 **`F12`** 키를 누르면 즉시 모든 타이핑이 중단됩니다.

## 🛠️ 기술 스택

- **Language**: Python 3.11 (`.venv` 가상환경)
- **GUI Framework**: `CustomTkinter` (모던 다크/라이트 테마 지원)
- **Keyboard & OS Control**: `pynput`, Windows Win32 API (`ctypes`, `user32.dll`, `imm32.dll`)
- **Testing**: `pytest`

---

## 🚀 시작하기

### 1. 가상환경 및 의존성 설치
```powershell
# 가상환경 생성
python -m venv .venv

# 의존성 패키지 설치
.\.venv\Scripts\pip.exe install -r requirements.txt
```

### 2. 프로그램 실행

#### 방법 1: 배치 파일로 간편 실행 (권장)
프로젝트 루트의 **`run.bat`** 파일을 더블 클릭합니다.

#### 방법 2: 터미널에서 실행
```powershell
.\.venv\Scripts\python.exe src\main.py
```

## 📖 사용 방법

1. **대상 창 선택**:
   - 메모장(Notepad) 등 타이핑할 창을 열어둔 뒤, 우측 상단의 **`🔄 창 목록 새로고침`**을 클릭하여 대상 창을 선택합니다.
   - 직접 클릭하여 입력 위치를 잡으려면 **`⚡ [수동 포커스]`** 옵션을 선택합니다.
2. **텍스트 입력**:
   - 중앙 텍스트 입력창에 타이핑할 글을 입력하거나 붙여넣습니다 (`Ctrl + V`).
3. **옵션 설정**:
   - **타이핑 속도**: 최소 타수와 최대 타수 지정 (기본: `200` ~ `300` 타/분).
   - **타이핑 정확도**: `0%` ~ `100%` 지정 (기본: `94%`, 오타 후 백스페이스 수정).
   - **준비 시간**: 시작 버튼 클릭 후 대기 시간 (기본: `3초`).
4. **타이핑 시작**:
   - **`▶ 타이핑 시작 (Start)`** 버튼을 누릅니다.
   - 비상 정지가 필요할 때는 언제든 키보드의 **`ESC`** 또는 **`F12`** 키를 누르세요.
